## 2. 玩家机制设计

### 2.1 防御（Block）

- **操作**：新增输入动作 `Block`（建议：鼠标右键长按 / 手柄 LT），按住进入防御，松开结束。
- **状态机**：Block_Start → Block_Loop ↔ Block_Guard → Block_End；移动中按防御时先 Step_Back 缓冲再进入 Block_Loop。
- **数值（初值）**：
  - 物理减伤 **80%**，即格挡时承受 20% 伤害（穿透伤害不致死：最多扣到 1 血）
  - 格挡成功吸收一次攻击消耗体力 = 攻击方"破防值"（轻击 12 / 重击 25 / 跳跃砸地 35）
  - 体力不足以支付破防值 → **破防（Guard Break）**：进入 Stun（约 1.2s 大硬直），怪物获得处决机会
- **方向性**：只防御正面 120° 扇形（配合锁定），左/右后方来袭用 Damage_Left/Right 受击——鼓励走位与锁定管理。

### 2.2 精准防御（Perfect Guard / 弹反）

- **判定**：怪物伤害**命中前 0.20s 内**按下 Block（即 Block_Start 动画前 0.2s 命中）判定成功。
  - 初值窗口 0.20s，手感测试后微调（黑魂 ~0.25s，只狼 ~0.3s 含预输入缓冲）
- **成功效果**：
  - 伤害 0、体力 0 消耗；播放 **Block_Guard**（弹开姿势）+ 叮声 + 白色火花特效 + 60ms 顿帧（hitstop）
  - **轻/中攻击的怪物进入弹反硬直**（复用怪物 TakeDamage 或 Hit Ground，约 0.8~1.5s）
  - 弹反后 1.0s 内玩家攻击伤害 ×1.5（惩罚窗口）
- **失败惩罚**：窗口外按格挡 = 普通格挡逻辑，但 Block_Start 前摇（~0.15s）期间被打 = 完整受伤——**弹反是高风险选择，不是保底选项**
- **不可弹反的攻击**：投技、跳跃砸地等"红光技"（见 §3.3）——弹反对红光无效，防止弹反万能化

### 2.3 体力经济（博弈的资源基础）

| 行为 | 消耗（初值） |
|---|---|
| 轻攻击 | 12 |
| 重攻击 | 20 |
| 翻滚 | 25 |
| 格挡吸收 | 12~35（随攻击） |
| 精准防御 | 0（奖励完美操作） |
| 破防被击 | 额外 -20 并清空 |
| 恢复 | 停止行动 0.5s 后 35/s |

设计意图：**连续进攻会打空体力，被迫进入防御/后撤节奏**——魂类"几刀一喘息"的核心循环。

### 2.4 处决（Riposte，M4 期实现）

- 触发：怪物处于弹反硬直 / 破防 Stun / Knockdown 状态时，靠近按重攻击
- 动画：先复用 `Knockdown_Front_Up`（怪物）+ `Attack_10` 附近的下劈（玩家）做简易处决；后续如需专属处决动画再购补充包
- 收益：处决 = 怪物最大血量 25~30%，处决期间玩家无敌

### 3.1 招式数据结构扩展（`EnemyAttackDefinition` / StoneGolemAttackDefinition）

### 3.2 石头人招式扩充（素材现成，零新增动画）

| 招式 | 动画 | 性质 | 博弈作用 |
|---|---|---|---|

| 跺地 AoE | Hit Ground | 黄光，可格挡高破防 | 逼玩家收刀防御或滚出范围 |

### 3.3 攻击预警分级（博弈可读性）

- **普通攻击**：无特效，正常格挡/弹反/翻滚均可
- **黄光（Guard 高破防）**：前摇时武器泛黄光（自发光材质粒子，复用 FX 包），可格挡但大扣体力，**建议翻滚**
- **红光（Unblockable）**：前摇泛红光，格挡无效、弹反无效，**必须翻滚或拉开距离**；石头人跳跃砸地与 Dragon 火息专属

### 3.4 新怪路线图（按实现成本排序）

1. **Forest Wolf ×2**（M3）：快攻双狼夹击，Bite 连段快、Claw 扫尾部、双狼交替压向两侧——训练走位而非站桩
2. **Nymph Fairy**（M3）：远程 ThrowProjectile，配合地面怪形成"远程+近战"压力组合，逼迫玩家使用突进/掩体
3. **Fantasy Dragon BOSS**（M4）：地面阶段（Bite/Projectile/Spell）→ 50% 血起飞（FireBreathOnce 横扫 + 飞行位移）→ 落地硬直给输出窗口——完整二阶段 BOSS

## 4. 博弈矩阵（核心循环）

| 怪物行为 | 玩家最优解 | 玩家贪心解（高风险高回报） |
|---|---|---|
| 普通连段 | 翻滚拉开 | **精准防御**（0 耗费 + 硬直 + 增伤窗） |
| 黄光高破防 | 翻滚 | 格挡（扣大量体力，攒破防风险） |
| 红光不可格挡 | 翻滚/跑开 | 无（强行贪输出 = 挨满伤） |
| 怪物 Defend | 绕后 / 等待 | 重击破防（消耗体力但立即破防） |
| 延迟连段 | 第二段出了再滚 | 提前滚 → 挨第三段 |
| 怪物 Stun/倒地 | 处决 | —— |

反制链：**玩家防御** → 怪物用 Defend/抓投反制站桩 → 玩家用红光技能打怪 Defend → 怪物红光技不可挡 → 玩家弹反普通技…… 任何单一策略都不万能。
