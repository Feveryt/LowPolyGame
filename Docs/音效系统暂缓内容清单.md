# 音效系统暂缓内容清单

本文记录首版核心音效系统暂不实现的内容，避免后续迭代时误认为这些功能已接入。

## 暂不接入的游戏声音

- 玩家脚步声：步行、跑步、不同地表材质与落地声。
- 玩家受击与死亡声：需要先确定受击动画事件、死亡流程和合适的角色素材。
- 世界交互声：场景机关、门、宝箱、可破坏物、传送点等。
- 环境声与环境发声点：风声、水声、火焰、动物、区域氛围和随机环境事件。
- 石头守卫待机声：呼吸、碎石摩擦、巡逻或发现玩家提示声。
- 其他敌人的攻击、受击和死亡声。

## 暂不接入的音乐

- 主菜单背景音乐。
- 探索区域循环背景音乐。
- 战斗背景音乐与战斗状态切换。
- 剧情、任务完成和 Boss 战的专属音乐。

## 暂不实现的音频功能

- 音量设置面板、静音开关和分类音量控制。
- Audio Mixer、混音快照、动态压缩和侧链处理。
- UI 键盘焦点移动声与鼠标悬停声。
- 依据材质、距离、遮挡或房间空间自动变化的声音效果。
- 运行时音频加载、资源分包和高级性能分析。

## 后续接入前需确认

- 每种新增声音对应的准确触发时机，优先使用动画事件或伤害结算事件。
- 素材是否适合当前低多边形奇幻风格，以及商业发布许可证是否有效。
- 3D 声音的最小距离、最大距离和同屏并发数量。
- 音乐的场景划分、循环点、切换规则及与音效的音量平衡。
