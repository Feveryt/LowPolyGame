# 编辑器一次性工具清理记录

记录日期：2026-09-15

## 背景

RPG 与工具菜单下的一批安装器在对应功能落地后已经没有重复执行的价值，其中几个脚本写死的输出路径还和项目当前结构不一致，重跑会生成重复资源或覆盖手工调好的配置。本文记录删除了哪些工具、为什么删除、产出的资源在哪，以及需要时如何恢复。

## 已删除的工具

### StoneUiSetup（原菜单：RPG/Setup/Build Stone UI）

- 职责：生成石质 UI 主题与库存、设置、对话相关预制体，并向 GameStart、TestAct 写入 HUD、对话画布、设置实例和道具图标引用。
- 产出资源：`Assets/Resources/UI/StoneUiTheme.asset`、`Assets/Resources/Prefabs/UI/InventorySlot.prefab`、`Assets/Resources/Prefabs/UI/Inventory Panel.prefab`、`Assets/Resources/Prefabs/UI/SettingsCanvas.prefab`、`Assets/Resources/Prefabs/UI/DialogueChoiceButton.prefab`，以及 GameStart、TestAct 场景中的既有界面。这些都是游戏正式资源，全部保留。
- 删除原因：脚本内的输出常量仍指向 `Assets/Prefabs/UI/` 与 `Assets/Resource/Inventory/` 等旧路径，实际预制体已迁到 Resources 下。重跑会在旧路径新建重复预制体，并重新覆盖两个场景。

### QuestPanelSetup（原菜单：RPG/Setup/Create Quest Panel）

- 职责：生成任务面板及其列表单元、目标子预制体，并绑定石质主题与运行时控制器引用。
- 产出资源：`Assets/Resources/Prefabs/UI/QuestPanel.prefab`、`QuestListItem.prefab`、`QuestObjectiveView.prefab`，均为任务面板运行时加载的正式资源。
- 删除原因：三个预制体已齐备，属于一次性生成器。

### ShopPanelPrefabSetup（原菜单：RPG/Setup/Create Shop Panel）

- 职责：生成商店面板预制体；并带 `[InitializeOnLoad]`，在预制体缺失时于脚本重载后自动补建。
- 产出资源：`Assets/Resources/Prefabs/UI/ShopPanel.prefab`。
- 删除原因：预制体已是正式资源；一次性使命完成。自动补建行为随之移除，后续注意事项见文末。

### AudioSetup（原菜单：工具/音频/安装核心音效，含英文别名 工具/Audio/Install Core Audio）

- 职责：创建并填充 `SoundLibrary` 资产，把 `AudioManager` 挂到 GameStart、TestAct、Demo 1，并为场景中的石头守卫补 `StoneGolemAudio`。
- 产出资源：`Assets/Resources/Audio/SoundLibrary.asset`、三个场景中的 `AudioManager` 对象、TestAct 中石头守卫的 `StoneGolemAudio` 组件。
- 删除原因：安装已完成。脚本内的音量、音高、冷却、并发等参数是硬编码的，重跑会覆盖 `SoundLibrary` 里手工调好的数值。

### UnsignedGuardianInstaller（原菜单：工具/未署名的守卫/安装剧情内容）

- 职责：创建两个顺序任务资产与记录员对话资产，向 Demo 1 写入 NPC 对话绑定、两个任务上报物和石头守卫配置，并把 Demo 1 登记进构建列表。
- 产出资源：`Assets/Resources/Quests/Quest_unsigned_guardian_lost_page.asset`、`Quest_unsigned_guardian_guardian_testimony.asset`、`Assets/GameData/Definitions/Dialogue/Dialogue_UnsignedGuardian.asset`，以及 Demo 1 中 NPC_1 的对话绑定与「无署名记录页」「封印铭片」两个 `QuestWorldReporter`。
- 删除原因：脚本中的对话输出路径仍是 `Assets/Dialogue/`，与实际存放位置 `Assets/GameData/Definitions/Dialogue/` 不一致。重跑会在旧路径新建一份重复对话资产，并覆盖既有剧情配置。

## 同时清理的代码

`ShopPanel.BuildPrefabLayout()`（`Assets/Scripts/UI/Shop/ShopPanel.cs`）仅供已删除的 ShopPanelPrefabSetup 构建预制体时调用。运行时由 `Awake` 加载 `StoneUiTheme` 并调用 `EnsureUi`，因此删除该方法不改变游戏表现。

## 保留的工具

- `工具/对话编辑器`、`工具/对话/清除已完成进度`（DialogueEditorWindow）
- `工具/镜头序列录制器`（CameraSequenceRecorderWindow）
- `工具/Low Poly Game/剧情/清除剧情存档`、`工具/Low Poly Game/剧情/重置剧情并重新开始`（StoryDebugTools）
- `RPG/Validation/Validate Character Stats`（CharacterStatsValidationTool）

以上工具只读取资源或提供反复使用的编辑、调试能力，不属于一次性安装器。

## 未受影响的资源

本次只删除编辑器脚本与一处死代码。所有场景、预制体、ScriptableObject 资产以及 `AudioManager`、`StoneGolemAudio`、`QuestWorldReporter`、`ShopPanel`、`QuestPanel` 等运行时组件保持原样，游戏内容不变。

## 注意事项

- 新增场景需要音效时，手工创建空对象并挂上 `AudioManager` 组件即可；音效配置仍由 `Resources/Audio/SoundLibrary` 自动加载。
- `ShopPanel.prefab` 丢失或损坏后不再自动重建，需要手工修复预制体，或从 Git 历史取回预制体文件。
- 音效参数的后续调整请直接在 `Assets/Resources/Audio/SoundLibrary.asset` 的 Inspector 中修改。

## 恢复方式

优先从 Git 历史取回脚本，而不是手工重建：

```powershell
git log --oneline -- Assets/Scripts/Editor/AudioSetup.cs
git checkout <commit> -- Assets/Scripts/Editor/AudioSetup.cs
```

恢复后重新编译，菜单项会重新出现在 RPG 或工具菜单下。注意本文列出的脚本存在路径过期的隐患，恢复后若直接执行会生成重复资源，请先确认是否真的需要重跑。
