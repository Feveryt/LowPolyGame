# 🗡️ LowPoly ARPG

> 一个使用 **Unity + GitHub Copilot** 协作开发的低多边形动作角色扮演游戏（ARPG）学习项目。

---

## 🎯 关于本项目

这是一个**正在开发中**的 Unity 学习项目，主要目的是通过实际制作一款 ARPG 游戏来深入学习 Unity 引擎的各个方面。项目中的所有代码均在 **GitHub Copilot / AI** 的辅助下编写，用于探索 AI 辅助游戏开发的可行性与最佳实践。

> ⚠️ **注意：** 本项目处于早期开发阶段，框架和功能会频繁调整迭代，代码、结构、美术资源等均可能发生较大变化。

---

## 🎮 游戏简介

- **类型：** 第三人称动作角色扮演游戏（ARPG）
- **美术风格：** Low Poly 低多边形
- **视角：** 第三人称自由视角（Cinemachine FreeLook）
- **核心玩法：**
  - 自由探索 3D 场景
  - 实时战斗系统（轻攻击连段 / 重击 / 技能释放）
  - 角色养成（等级、属性、技能树）
  - 装备与背包系统
  - 多种敌人 AI（巡逻 / 追击 / BOSS 战）
  - 任务与剧情对话系统

---

## 🛠️ 技术栈

| 类别 | 技术 |
|------|------|
| 引擎 | Unity 6 |
| 渲染管线 | Universal Render Pipeline (URP) |
| 语言 | C# |
| 相机 | Cinemachine (FreeLook) |
| 角色控制 | CharacterController |
| AI 辅助 | GitHub Copilot |

---

## 📁 项目结构

```
Assets/Scripts/
├── Framework/       # 框架核心（GameManager, EventManager, AudioManager 等）
├── Player/          # 玩家系统（移动、战斗、属性、技能、背包、动画）
├── Enemy/           # 敌人系统（AI、属性、刷怪、动画）
├── UI/              # 界面系统（HUD、背包、技能树、对话、暂停菜单）
├── Combat/          # 战斗逻辑（伤害计算、Buff、弹道、打击检测）
└── Data/            # 数据结构定义（物品、技能、敌人配置、存档）
```
