日期：2026年8月13日
------------------------------------
今日完成内容
------------------------------------

1. QFramework 架构整合
   - 引入 QFramework.cs 官方核心（724 行，MIT）
   - GameArchitecture 架构入口 + GameStateModel/GameStateSystem/ChangeGameStateCommand
   - 完整事件流：表现层 -> Command -> Model -> System -> 事件广播
   - PlayerController 实现 IController，监听暂停事件禁用输入

2. Input System 整合
   - 安装 Input System 1.7.0，切换纯新输入系统
   - PlayerAction.inputactions：Move/Look/Sprint/Equip/HeavyAttack/LockOn
   - 键鼠 + 手柄双控制方案（带摇杆死区）
   - InputManager 输入门面 + 编辑器工具一键配置预制体
   - 修复 CursorManager 旧 Input API 兼容问题

3. 双相机模式系统（借鉴开源项目）
   - 探索模式（未持武器）：FreeLook 自由环绕 + SpringArm 防穿墙
     （SphereCast 遮挡检测，按比例收缩三环半径；参考 dbrizov/Unity-CharacterController）
   - 战斗模式（持武器）：锁定环绕相机 + Tab 锁定最近敌人
     （相机位于"玩家-目标"连线玩家后方；参考 mishanyaqq/Erbium）
   - CameraModeController（模式切换 + 运行时自动创建战斗相机）
   - LockOnController（角度优先锁定 + 死亡/摘武器自动解锁）
   - 相机模式随 R 键装备切换，与双动画树（装备/未装备）对应

4. 重攻击三段连击
   - PlayerCombat：Attack_17 -> Attack_18 -> Attack_14
   - 输入缓冲 + 连击窗口（comboInputStart/End）
   - 攻击期间禁用移动与装备切换
