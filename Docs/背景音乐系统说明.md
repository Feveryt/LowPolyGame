# 背景音乐系统说明

记录日期：2026-09-15

## 目标与现状

游戏使用 `Assets/Audio/BGM/遗迹探索-废弃城堡V2.ogg` 作为全局背景音乐，GameStart、TestAct、Demo 1 三个场景共用同一首。切换场景时音乐持续播放，不会中断或从头开始。

## 常驻机制

音乐播放器由 `Assets/Scripts/Audio/BgmManager.cs` 提供。它在首个场景加载后自动创建，并调用 `DontDestroyOnLoad`，因此从任意场景启动都存在且只有一个播放器，不需要往场景里手动挂载组件，也不需要修改任何场景文件。

如果确实需要在 Inspector 里调参，也可以在场景中手动放置一个 `BgmManager`，此时以场景实例为准，自举逻辑检测到已有实例后不会重复创建。

场景切换通过 `SceneManager.sceneLoaded` 监听：解析出的曲目与当前曲目相同则保持播放，不同时才淡出换曲。

## 配置方式

配置资产位于 `Assets/Resources/Audio/BgmLibrary.asset`：

- `defaultTrack`：未匹配到场景覆盖时使用的默认曲目，当前指向 `遗迹探索-废弃城堡V2.ogg`，基础音量 0.5，开启循环。
- `sceneTracks`：按场景覆盖曲目的列表，当前为空。以后要让主菜单和游玩场景播放不同音乐时，在这里新增条目并填写场景路径即可。

场景路径既可以写完整路径（`Assets/Scenes/GameScene/Demo 1.unity`），也可以只写场景名（`Demo 1`），匹配时忽略大小写和路径分隔符差异。

要更换全局音乐，把 `defaultTrack` 的 Clip 换成新片段即可；想单独给某个场景换曲，就在 `sceneTracks` 里加一条覆盖。

## 音量接口

音量由 `Assets/Scripts/Audio/AudioVolumeSettings.cs` 统一管理，分为音效与背景音乐两条独立通道，数值范围 0 到 1，持久化在 PlayerPrefs 的 `Audio.SfxVolume` 与 `Audio.BgmVolume` 键中。

默认值都是 1：音效通道为 1 表示保持既有响度不变，音乐通道为 1 表示使用曲目配置里的设计音量（当前 0.5）。音乐的最终音量 = 曲目基础音量 × 音乐通道音量。

以后在设置面板加滑条时，直接把滑条的数值接到接口即可：

```csharp
// 绑定滑条：拖动时写入设置，初始化时读取当前值
volumeSlider.value = AudioVolumeSettings.BgmVolume;
volumeSlider.onValueChanged.AddListener(AudioVolumeSettings.SetBgmVolume);
```

音乐管理器订阅了 `AudioVolumeSettings.Changed`，音量变化会立即生效，并在稳定播放阶段做平滑过渡，因此拖动滑条不会出现爆音。恢复默认值可调用 `AudioVolumeSettings.ResetToDefaults()`。

## 淡入淡出

- 首次播放淡入 1.5 秒。
- 换曲或停止时淡出 1 秒。
- 淡入淡出使用 `Time.unscaledDeltaTime`，打开设置面板暂停游戏（`timeScale = 0`）时音乐照常播放与过渡。

## 已知限制

这首音乐未必是严格无缝循环素材。如果循环接缝听起来断裂，可以改成双声源交叉淡化循环，属于独立的小改动，不影响现有接口。

音效的音量通道已经接入 `AudioManager`，但设置面板目前仍没有音量滑条，这一部分尚未实现。
